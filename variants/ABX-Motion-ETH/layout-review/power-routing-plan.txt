2026-10-24 | PHYSICAL PLACEMENT ONLY | no copper routing / no schematic integration

DECISION
Use protected +BATT, after Q1, to supply a separate Ethernet buck. Do not take
Ethernet power from U2 or consume the agreed external 1A allocation on +5V.
The new converter does not remedy the previously identified full-allocation
shortfall of the original supply; that issue remains separate.

POWER DESIGN BASIS
- Normal input maximum32V; the existing TVS contract specifies40V clamp.
  U802 is65V rated; input capacitors50V. This does not qualify motor-regeneration
  surges or establish the real transient envelope of the whole board.
- Converter class600mA; planned Ethernet allocation300mA, not a new external port
  rating. W5500's132mA typical transmit figure is not a maximum guarantee.
- RT(pin1) directly to internal VCC(pin7): TI's1MHz fixed3.3V example,15uH and
  2x22uF. No external feedback divider or RT resistor is necessary.
- At32V, minimum selected inductance12uH and f=0.93MHz give about265mA ripple;
  at600mA the approximate peak is733mA. Confirm current-limit margin from the
  final datasheet limits and real waveforms. L801 Isat minimum1.65A, RMS1.11A;
  regulator high-side current-limit maximum1.11A. These are different ratings.
- 2x4.7uF input is a placement for DC-bias margin. Require combined EFFECTIVE
  input capacitance >=2.2uF at32V/temperature; nominal9.4uF alone proves nothing.
- C824 sees the BOOT-SW differential, not the battery voltage;16V is adequate
  for the internal gate-drive supply. Never reuse this16V part on VIN.
- R81710k from existing main +3V3, R818100k to GND: buck follows main logic
  presence. EN is about3.0V at nominal main3V3. PGOOD pin2 is unused.
- USB-only, without battery: Ethernet is deliberately off. Independent supply
  isolation prevents its SPI pins drawing power from the active MCU rail.
- Output tolerance, efficiency/loss and thermal rise require load/ambient tests;
  the600mA silicon rating is not a measured board thermal qualification.

   All original segments/vias/zones currently survive verbatim, including copper
   under the new footprints and moved original test pads/pull-ups. It cannot be
   used as finished routing for the new placement. Preserve unrelated connections.
3. Route the new buck locally before its supply trunk or control lines:
   +BATT enters from the RIGHT, from Q1 source atx162.1,y61.595 or a verified
   low-impedance point on the SAME protected net. Do not use V_FUSED on Q1 drain.
   C821/822 VIN pads face UP; GND pads face DOWN. C823 VIN pad2 is to the RIGHT; its GND pad1 is to the LEFT.
   Join VIN bulk -> C823.2 -> U802.4 with short, wide front copper. Keep
   C823.1 -> U802.9 return compact. Do not make the HF loop visit the bulk caps.
   Measured pad-center separations: VIN/HF1.92mm, HF GND/IC GND2.85mm.
   Run front GND from C823.1 through the center gap between VIN/SW corner
   lands to ground9; the0.35mm spine has about0.275mm lateral pad clearance.
   This keeps the HF return local rather than forcing it through two vias.
   These are geometric lower bounds, not already routed trace lengths.

POWER SEQUENCING / SHARED-SPI REQUIREMENT
U804 has VCCA=main+3V3 and VCCB=3V3_ETH, with Ioff/supply-disconnect behavior.
Map A1/B1=SCLK, A2/B2=MOSI, A3/B3=CS_N, B4/A4=MISO. Crucially, a push-pull MISO
buffer cannot be left enabled when W5500 is deselected: its input pull-down
would otherwise drive the shared stepper MISO line. Q802 inverts MAIN CS_N:
  MAIN CS_N HIGH -> Q802 ON -> OE LOW -> all buffer outputs high impedance.
  MAIN CS_N LOW  -> Q802 OFF -> R820 raises OE -> Ethernet selected.
R820 pulls to MAIN+3V3, R821 holds main CS inactive, R809 holds Ethernet CS
inactive while its translated output is disconnected. The MOS gate creates no
forward supply connection. Buffer rail-disconnect behavior is still required.

Start SPI mode0 at10MHz.20MHz is a qualification target, superseding the earlier
unguarded20MHz starting proposal; include both buffer delays in the read timing
budget. Allow2us before clocking after asserting main CS,2us hold after the last
edge, and2us deselect/bus turnaround initially. Configure hardware CS timings if
supported, or use manual GPIO CS under the bus lock; verify with a scope before
using the standard W5500 driver's default timings. This is an explicit firmware
requirement introduced by the CS-gated isolation stage, not transparent wiring.

Existing GPIO3/LED_STAT reassignment and U601 IO1_5/IO1_6 reuse are still pending.
U601 pads18/19 currently have GND connections in the root circuit. They cannot
be used until BOTH schematic and PCB ties are removed. Check GPIO3 strapping;
no eFuse changes are authorized or performed. No new MCU pin is assumed free.

RESET
TPS3808G33 monitors3V3_ETH on SENSE and VDD.3.07V threshold, worst accuracy1.5%
gives approximately3.024..3.116V, before considering hysteresis. CT left open
provides20ms nominal reset delay. RESET_OD has the existing10k pull-up to3V3_ETH.
Q801 pulls MR low from the expander request; its gate has100k pull-down. Assert
request >=1ms, release, wait>=30ms initially, then read the W5500 version/status.
Do not attach the supervisor reset pull-up to main3V3 or expose an unpowered PHY
to push-pull reset. Keep CT unconnected with no measurement stub.
