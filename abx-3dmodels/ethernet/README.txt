Ethernet 3D model bundle for the root ABX-Motion project.
Stock STEP files are unmodified KiCad library models; their copyright/license
headers and accompanying license/credits are preserved.
HR911105A and LMR36506 WRL files are project dimension envelopes, not vendor
detailed models. These copies make the draft independent of versioned library
variables. BOM/CPL exclusion attributes are unchanged.
